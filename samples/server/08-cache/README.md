# キャッシュ戦略サンプル

サーバーサイドでのキャッシュ実装方法を学ぶサンプルです。

## ファイル構成

```
08-cache/
├── 01-memory-cache/   # インメモリキャッシュ
├── 02-redis/          # Redis（分散キャッシュ）
└── 03-http-cache/     # HTTPキャッシュヘッダー
```

## キャッシュの種類

| 種類 | 場所 | 特徴 | 用途 |
|------|------|------|------|
| **インメモリ** | サーバーメモリ | 最速、単一サーバー | 計算結果、API応答 |
| **Redis** | 外部サーバー | 高速、分散対応 | セッション、ランキング |
| **HTTPキャッシュ** | ブラウザ/CDN | 通信不要 | 静的ファイル、API |

## いつ何を使う？

### インメモリキャッシュ
- 単一サーバー構成
- 起動時に再生成可能なデータ
- 最速のレスポンスが必要

### Redis
- 複数サーバー間で共有
- セッションストア
- リアルタイムランキング
- レート制限

### HTTPキャッシュ
- 静的ファイル（JS, CSS, 画像）
- 頻繁に変わらないAPIレスポンス
- CDN活用

## 学習の流れ

1. `01-memory-cache/` - Node.jsでのシンプルなキャッシュ
2. `02-redis/` - Redisの基本操作と実践パターン
3. `03-http-cache/` - Cache-Controlヘッダーの使い方

## セットアップ

```bash
# Redis用
npm install redis

# Redisサーバー起動（Docker）
docker run -d -p 6379:6379 redis
```
