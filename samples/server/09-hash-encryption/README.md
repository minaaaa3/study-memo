# ハッシュと暗号化サンプル

セキュリティ関連の実装方法を学ぶサンプルです。

## ファイル構成

```
09-hash-encryption/
├── 01-hash/        # ハッシュ関数
├── 02-password/    # パスワードハッシュ
└── 03-encryption/  # 暗号化・復号
```

## ハッシュ vs 暗号化

| 種類 | 方向 | 用途 |
|------|------|------|
| **ハッシュ** | 一方向（復元不可） | データ検証、パスワード保存 |
| **暗号化** | 双方向（復元可能） | 機密データの保護 |

## よくある間違い

```
❌ パスワードを暗号化で保存 → 復号されたら終わり
✅ パスワードはハッシュで保存 → 元の値を知る必要なし

❌ MD5/SHA1でパスワードハッシュ → 高速すぎて総当たり攻撃に弱い
✅ bcrypt/Argon2を使用 → 意図的に遅く設計されている

❌ 自作の暗号化アルゴリズム → 専門家でも難しい
✅ 標準的なライブラリを使用 → AES-256等
```

## いつ何を使う？

### ハッシュ関数（SHA-256等）
- ファイルの整合性チェック
- データの重複検出
- APIリクエストの署名

### パスワードハッシュ（bcrypt/Argon2）
- ユーザーパスワードの保存
- 認証時の照合

### 暗号化（AES）
- APIキーの保存
- 個人情報の保護
- 通信の暗号化

## 学習の流れ

1. `01-hash/` - ハッシュの基本と用途
2. `02-password/` - bcryptでのパスワード管理
3. `03-encryption/` - AESによる暗号化・復号
