# Push型通信サンプル

サーバーからクライアントにリアルタイムでデータを送る方法を学ぶサンプルです。

## ファイル構成

```
07-push-communication/
├── 01-polling/     # ポーリング（従来方式）
├── 02-sse/         # Server-Sent Events
└── 03-websocket/   # WebSocket
```

## 方式の比較

| 方式 | 方向 | 接続 | 用途 |
|------|------|------|------|
| **ポーリング** | クライアント→サーバー | 毎回新規 | シンプルな更新チェック |
| **SSE** | サーバー→クライアント | 永続（片方向） | 通知、フィード更新 |
| **WebSocket** | 双方向 | 永続（双方向） | チャット、ゲーム |

## いつ何を使う？

### ポーリング
- 数秒〜数分間隔の更新で十分
- シンプルな実装を優先
- レガシーブラウザ対応

### SSE（Server-Sent Events）
- サーバー→クライアントの一方向通知
- 自動再接続が欲しい
- HTTP/2との相性が良い
- 例: 株価、ニュースフィード、進捗状況

### WebSocket
- 双方向のリアルタイム通信が必要
- 低レイテンシが重要
- 例: チャット、オンラインゲーム、共同編集

## 学習の流れ

1. `01-polling/` - まず従来方式を理解
2. `02-sse/` - サーバーからの一方向通信
3. `03-websocket/` - 双方向のリアルタイム通信

## セットアップ

```bash
# WebSocket用
npm install ws

# Socket.IO（より高機能）
npm install socket.io socket.io-client
```
