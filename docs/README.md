# Web開発 基礎から実践まで

## このサイトについて

「TypeScriptやReactは触ったことあるけど、結局何が起きてるかわからない」
「AIに聞けば動くコードは書けるけど、なぜ動くのかは説明できない」

そんなエンジニアのための学習サイトです。

### 学習の進め方

- **例え話から入る**: 難しい概念も、身近なものに例えてから説明します
- **コードで確かめる**: 読むだけでなく、実際に動かして確認します
- **「なぜ」を大切に**: 「こう書けば動く」ではなく「なぜそう書くのか」を理解します

## 各章の構成

すべての章は以下の構成になっています：

1. **例え話**: 身近なものに例えて概念を掴む
2. **核心**: 技術的に正確な説明
3. **コードで確認**: 実行して動作を確かめる
4. **よくある誤解**: 間違いやすいポイント
5. **自前 vs ライブラリ**: 実装の選択肢を知る
6. **まとめ**: 重要ポイントの振り返り
